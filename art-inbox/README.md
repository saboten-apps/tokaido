# 絵の取り込み場所

浮世絵風の絵（マスの絵）を、ここへ置いて、`node scripts/importArt.mjs` を実行します。

- ファイル名は **マスの名前**（`src/data/board.json` の `name`）：`箱根.png`、`日本橋.jpg`、`大井川.webp` など。
- 形式：png・jpg・webp。正方形に近いものがよい（中央を、192×192 に切り抜きます）。
- 実行すると、`public/art/<名前>.webp` に変換され、`src/art/overrides.json` に登録されます。**変換後の webp と overrides.json は git に入れます。元の画像（この場所）は、git に入れません。**
- 絵がないマスは、仮の絵（色と記号）のままです。

素材の権利に注意してください。広重の原画そのものは、パブリックドメインですが、美術館が撮影した写真には、権利や利用条件が付くことがあります。使う前に、所蔵館の利用条件（CC0・オープンアクセスなど）を確かめ、出典を `docs/ASSETS.md` に記録してください。
