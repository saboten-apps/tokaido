# 素材（絵・音）の記録

絵を足したら、ここに、**出どころ・権利・利用条件**を書く。

## いまの絵
- すべて仮の絵（`src/art/theme.ts` の色と記号）。アイコン（`public/favicon.svg`・`icon-*.png`）は、このプロジェクトで作った図形（権利の問題なし）。

## 絵の足し方（浮世絵風など）
1. `art-inbox/` に、マスの名前のファイル（`箱根.png`）を置く（手順は `art-inbox/README.md`）。
2. `node scripts/importArt.mjs`（`public/art/箱根.webp` に変換し、`src/art/overrides.json` に登録）。
3. `npm run check`・`npm run test:e2e`。変換後の webp と overrides.json をコミットする（元の画像は、コミットしない）。
4. 下の表に、1行足す。

| マスの名前 | ファイル | 出どころ（作者・所蔵館・URL） | 権利・利用条件 | 取り込み日 |
|---|---|---|---|---|
| （まだなし） | | | | |

## 権利の注意
- 歌川広重『東海道五拾三次』の**原画**は、パブリックドメイン（作者の没後、長い年月が経っている）。
- ただし、**美術館・図書館が撮影・公開している画像**には、利用条件が付くことがある。CC0・オープンアクセスの表記があるものを選び、条件を確かめてから使う。
- 生成した絵を使う場合は、生成の手段の利用条件と、既存の作品に似すぎていないかを確かめる。

## 広重『東海道五拾三次』の絵（2026-11-17）
- **題名はすべて入っている**（`src/data/hiroshige.json`、保永堂版55図。板の宿名と副題。例：由井・荒井・赤阪・坂之下・京師）。場所の解説カードと、結果の手帖に出る。**絵そのものは、まだ入っていない**（絵がなければ「絵は準備中」）。
- 絵が入ると、場面の右上に小さく出て、押すと大きく見られる（題名・出どころ・所蔵館のページつき）。
- 入れ方（どちらか）：
  1. 手元の画像：`art-inbox/hiroshige/<マスの名前>.jpg`（例：箱根.jpg）を置き、`npm run import:hiroshige -- --credit "出どころ・権利の表示"`。図ごとに違う出どころは `art-inbox/hiroshige/credits.json`。**出どころ（credit）のない絵は、取り込まない**。
  2. メトロポリタン美術館のオープンアクセス（CC0）：`npm run import:hiroshige -- --met` で候補の一覧（資料番号・題名・年代）を出す → 見て、よければ `-- --met --apply`。版の違う資料が混ざるときは `--min` / `--max` で資料番号の範囲を絞る。画像を取るには、`collectionapi.metmuseum.org` と `images.metmuseum.org` への接続が要る。
- 権利：広重の原画はパブリックドメイン。美術館が撮影した画像の利用条件は、館ごとに違う。メトロポリタン美術館のオープンアクセスの画像は CC0（`isPublicDomain` のもの）。使った絵は、下の表に1行ずつ足す。
