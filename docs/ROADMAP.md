## A：ゲームの芯（ルール）

### A1 早足（全員が使える、時間と体力の取り引き）
- 手番で「振る」「働く」に加えて「**早足で振る**」：出目＋2マス、体力 −10。
- 狙い：急ぎ旅の利点を、性格ではなくルールに持たせる。人間にも「急ぐか、休むか」の判断ができる。CPU の急ぎ旅は早足を多用する。
- 数値は `balance.json` の `travel.hurry*`。構造の変更なし（行動が1つ増えるだけ）。

### A2 宿の格（宿場に泊まるときの選択）
- 宿場で日が終わるとき、泊まり方を選ぶ：**木賃宿**（安い・回復小）／**旅籠**（ふつう）／**評判が高いと本陣に招かれる**（無料・回復大・思い出＋。評判の効果の続き）。
- 人間は日の終わりに選ぶ必要があるので、判断待ち `inn` を足す（手番の終わり、宿場に止まったときに選ぶ形にして、日の終わりの処理は変えない）。
- `Player` に「今夜の宿」を持たせる → **SCHEMA_VERSION 2・移行・テスト**。

### A3 野宿の罰を「体力だけ」に整理
- 評判の減りはなくした（済）。野宿は体力 −8 のまま、**2日続くと次の日の出目が3まで**（疲れ）を強める。宿の格（A2）と合わせて、路銀の使い道に意味を持たせる。

### A4 思い出の使い道：称号と旅日記
- **称号**：思い出の節目（20・50・100）と特定の体験（関所を両方越えた、脇道で川明けを待った、名物10個 など）で付く。結果画面に出す。データは `src/data/titles.json`。
- **旅日記**：umaregacya の chronicle を作り直す。出来事・名物・関所・到着を、宿場名つきで残し、結果画面で「あなたの東海道」として読める。`GameState.diary` を足す → A2 と同じ SCHEMA 2 にまとめる。

### A5 バランスの目標（シミュレーションで確認）
- 4人で到着 35〜40日目、日数上限 60 で全員到着 99%以上。
- 流儀ごとの勝率が 18〜32% に収まる（いま：食い道楽34%・急ぎ旅14%）。
- 働く割合 10〜20%、野宿は1人 10回前後（いま17回）。

## C：2D の演出
- **駒の移動**：`rolled` の `path` を1マスずつたどるアニメーション（0.12秒/マス）。`prefers-reduced-motion` なら即時。
- **サイコロ**：振ったときに出目を大きく見せる（早足は「＋2」を添える）。
- **小地図**：画面上部に108マスの細い帯。全員の位置と、いま見ている範囲。帯を押すとそこへスクロール。
- **結果の通知**：出来事・名物・宿代の増減を、短い帯で数秒出す（いまは道中記を読まないと分からない）。
- **到着と結果**：三条大橋に着いたときの一枚、結果画面に称号と旅日記。
- e2e：アニメーション中も操作の順番が崩れないこと、`?fast=1` で演出を飛ばせること。

## H：旅人の身分（実装済み 2026-11-17。詳細は HANDOFF）
- 開始時に身分を1つ選ぶ（旅のあいだ変わらない）。案：商人（「働く」の稼ぎ多い）・伊勢参りの旅人（評判・名所の思い出が増えやすい）・飛脚（体力が多く早足が安い）・旅芸人（「働く」で思い出も増える）・武士（関所を手早く通る・宿代は高め）。
- 職業（就職・昇進・年収）は作らない。CPU の流儀は、身分に置き換える案。
- `Player.role` を足す → SCHEMA_VERSION 3・移行・テスト。数値は `balance.json` の `roles`。史実（飛脚の装束・武士の関所の扱い）は、資料で確認してから入れる。

## B：中身
- **専用イベント**：残り40宿。広重『東海道五拾三次』の図の題材と、『東海道中膝栗毛』の場面を手がかりに、話の濃い宿から10宿ずつ。史実の細部（料金・日数・年代）は資料で確認してから入れる（不確かなものは、言い伝え・〜と聞く、の書き方に）。
- **名物**：名物のない26宿。確かな名物がない宿は、無理に作らず「土地の話」の出来事で補う。
- **汎用の出来事**：16 → 40件（天気・道連れ・茶屋・旅芸人・病・忘れ物など）。同じ出来事が一旅で何度も出ないよう、汎用にも「一旅で2回まで」を入れる（SCHEMA 2 に含める）。
- **分かれ道を増やす**：候補は 宮〜桑名（七里の渡し／佐屋路）、箱根（山越え／別の道）。仕組みは複数の分かれ道に対応済み。脇道の旗の番号はテストで検出。

## D：複数人
- **D1 同じ端末で交代**：タイトル画面で人間の人数と名前を入れる（エンジンは `humanNames` 対応済み）。手番の人を大きく表示。
- **D2 オンライン**：umaregacya の `room.ts`・`src/online/`・`worker/`（ロビー・席・持ち時間・自動プレイ・Durable Object）を移植。OGP・計測・リダイレクトは持ってこない。
  - 必要なもの：Cloudflare の Worker 名、Cloudflare のトークン（この環境に登録）。プレビューは `wrangler versions upload`。

## E：絵
- `src/art/theme.ts` の `artOverrides` と、`board.json` の `art`（宿場ごと）で差し替え。画像は `public/art/`（webp、縦横の決まった大きさ）。
- 取り込みの手順（縮小・名前の決まり）を `scripts/importArt.mjs` に（umaregacya の手順を参考）。
- 素材の出どころ：自作／生成、または広重の原画（作品自体はパブリックドメインだが、美術館の写真には権利が付くことがある。CC0 の所蔵品に限るなど、使う前に確認）。
